## 🌟 Flagship Virtual Tour System (Inside The Villa)
Transition smoothly from the villa exterior into room-by-room exploration across 3 interactive modes:
- **MODE A: Cinematic Walkthrough**: Ambient floating camera motion with smooth transitions, progress timeline, room specs drawer, and interactive spatial hotspots.
- **MODE B: 360° Interactive Panorama Viewer**: Drag to look around 360 degrees horizontally and vertically, field-of-view zoom, and auto-rotation toggle powered by Three.js.
- **MODE C: Real-Time 3D Architectural Villa Model**: Real-time Three.js Canvas with orbital mouse drag/touch controls, illuminated floor levels, and architectural massing geometry.

### Ambient Audio
Includes an ambient sound engine built with Web Audio API that generates gentle breeze and meditative harmonic frequencies without external audio file overhead.

# 4. Production Build & Server

npm start
